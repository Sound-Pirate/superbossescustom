## Muscle Fatigue

Ajoute un système invisible de fatigue musculaire basé sur les actions du joueur. Miner, sprinter ou sauter augmente la fatigue, ce qui ralentit le joueur et réduit la vitesse de minage et de saut. Se tenir immobile ou marcher calmement permet de récupérer.
